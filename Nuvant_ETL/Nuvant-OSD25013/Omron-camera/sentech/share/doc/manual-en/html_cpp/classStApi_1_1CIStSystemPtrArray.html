Detailed Description

This class manages the lifetime of classes derived from IStSystemReleasable. The destructor of this class will automatically call IStSystemReleasable::Release().

IStDeviceReleasable* StApi::CIStSystemPtrArray::CreateFirstIStDevice ( GenTL::DEVICE_ACCESS_FLAGS  eDeviceAccessFlags = GenTL::DEVICE_ACCESS_CONTROL)

Acquire IStDeviceReleasable interface for the first device found (Device index = 0) in the system module.

Attention
If the IStDeviceReleasable interface pointer is no longer needed, call IStDeviceReleasable::Release().
Parameters
[in]eDeviceAccessFlagsDevice access flag.
Returns
Return IStDeviceReleasable interface pointer.
Exceptions
Throwout a GenICam::GenericException if memory allocation is failed or there is an invalid argument or GenTL function is failed.
