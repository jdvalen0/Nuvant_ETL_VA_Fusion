Detailed Description

template<class T, class UT>
class StApi::CStAutoPtrArray< T, UT >

This class represents an array of interface pointers. It will automatically finalize the assigned interface pointers.

Template Parameters
TInterface which is invoked during the termination process.
UTInterface for user to control.
