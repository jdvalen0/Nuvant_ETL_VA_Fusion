◆ CreateIStDataStream()

virtual IStDataStreamReleasable* StApi::IStDevice::CreateIStDataStream ( size_t  nIndex = 0,
IStAllocator *  pIStAllocator = NULL 
)
pure virtual

Open DataStream module of GenTL and acquire IStDataStreamReleasable interface pointer.

Attention
If the acquired interface pointer of IStDataStreamReleasable does not needed anymore, call IStDataStreamReleasable::Release() to release it.
Parameters
[in]nIndexIndex of the DataStream to open. It can be set as 0 to (GetDataStreamCount() - 1) .
[in]pIStAllocatorIStAllocator interface pointer for allocating and releasing memory. If NULL, the buffer memory allocation and deallocation are managed by StApi.
Returns
IStDataStreamReleasable Interface pointer.
Exceptions
Throwout a GenICam::GenericException if memory allocation is failed or there is an invalid argument or GenTL function is failed.
See also
StApi::CIStDataStreamPtr
