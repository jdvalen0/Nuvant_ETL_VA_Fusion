Change History of StApi

v1.1.2 Update 5 (2021.09.30)

Common

  • Support for HeartbeatTimeout updates after opening a GigEVision camera.
  • Support for saving pixel format conversion settings for StViewer preview images.
  • Added StBayerInterpolationMethod_BiLinear3 to the bayer color interpolation (demosaicing) method and changed it to be selected as the default format when saving still images.
  • Fixed a bug that the value type of function GetTimestampNS in IStStreamBufferInfo of StApiC is int64_t instead of uint64_t.

Windows

  • Add StViewer, StFWUpdater, and GigECameraIPConfig permission settings to firewalls during Sentech SDK installation.
  • Fixed a bug where the number of saved images setting did not work when using the continuous still image saving function in StViewer.
  • A 64 bit version of Tool (StFWUpdater, GigECameraIPConfig, StPowerCtrl) has been added to the installer so that Tool can be used without installing the 32 bit version of the DLL.
  • Fixed a bug that caused the text strings of the buttons on the node map settings screen to overlap in the Windows 11 environment.

Linux

  • Fixed a bug that could return GC_ERR_ERROR if the event occurred before calling EventGetData.
  • Fixed a bug where Acknowledge from a GigE Vision camera for ActionCommand could only be retrieved for the first time.

Mac

  • Fixed a bug that could return GC_ERR_ERROR if the event occurred before calling EventGetData.
  • Fixed a bug where Acknowledge from a GigE Vision camera for ActionCommand could only be retrieved for the first time.

v1.1.2 Update 4 (2021.04.30)

Common

  • Defects in calculation of (spacial) SN value of SN measurement filter have been corrected.
  • Fixed a bug that caused the frame rate to drop when using a CoaXPress camera.
  • The StApi::IStEdgeEnhancementFilter feature now supports the following formats:.
    • StPFNC_YCbCr8
    • StPFNC_YCbCr8_CbYCr
    • StPFNC_YCbCr709_8_CbYCr
    • StPFNC_YCbCr601_8_CbYCr
    • StPFNC_YUV8_UYV
    • StPFNC_YCbCr422_8
    • StPFNC_YCbCr709_422_8
    • StPFNC_YCbCr601_422_8
    • StPFNC_YUV422_8
    • StPFNC_YCbCr422_8_CbYCrY
    • StPFNC_YCbCr709_422_8_CbYCrY
    • StPFNC_YCbCr601_422_8_CbYCrY
    • StPFNC_YUV422_8_UYVY
  • The GenTL module now has the ability to manually set the USB3Vision camera's streaming payload size (ManualPayloadSizeMode, ManualPayloadSize).

Windows

  • Fixed a bug when importing PNG files.
  • StViewer now has the ability to save a series of still images.
  • Fixed a bug that caused NIC and GigE Vision camera IP address/subnet mask not to be displayed in the device selection window.
  • The function to save WebM format (VP8) movies is supported.
  • Support for non-USB3Vision cameras (STC-MBA5MUSB3/STC-MCA5MUSB3).
  • Fixed a bug that prevented the GigEVision camera from opening if the network portion of the NIC's subnet mask setting is not a multiple of 8 (Subnet mask contains a number other than 255 or 0 in the decimal notation).
  • Fix to stop CPU load remaining high when using ActionCMD with GigE Vision camera.
  • Fixed a bug that caused applications to terminate unexpectedly when exporting registry settings for DirectShow filters to a file.
  • Support .NET Framework 4.0. For details, please refer to StApiDotNET_Jpn.chm or StApiDotNET_Eng.chm.
  • Added StGevDelay for consideration of GevSCFTD and GevSCPD for GigE Vision cameras.

Linux

  • Fixed a bug that prevented GigE Vision cameras from opening on different subnets.
  • Added the ability to disable Zero Copy in some environments where it does not work and image data cannot be retrieved from a USB3Vision camera. Zero Copy is disabled if the environment variable "STGENTL_U3V_DISABLE_ZERO_COPY" is defined. Zero Copy is disabled when you launch the StViewer as follows:.
    $ export STGENTL_U3V_DISABLE_ZERO_COPY
    $ /opt/sentech/bin/StViewer

Linux

  • Fixed a bug that caused a timeout error when connecting a USB3Vision camera at high speed (USB 2.0).

  • Fixed a bug that caused a timeout error when connecting a USB3Vision camera at high speed (USB 2.0).

v1.1.2 (2020.04.30)

Common

  • Support for polarization sensors.
  • Added the ability to specify a color map (Palette) when displaying Mono 8 images or generating BMP/PNG/TIFF files.

Windows

  • The block size for JPEG/MotionJPEG data generation has been changed in order to cope with the problem of horizontal synchronization slippage when generating JPEG/MotionJPEG files based on images of a specific size (ex. 500 x 500).
  • Fixed a bug where the center coordinates may not be displayed when drawing a cross or ellipse.
  • You can specify the number of decimal places for the size display when drawing.
  • Fix bug that created event retrieval threads even when not retrieving camera events.
  • Fixed a bug that prevented streaming from resuming when using a switchover on a streaming GigEVision camera.
  • Added the ability to import still image files in StRaw format to the StViewer.
  • Change handling of the EventFlush function in the GenTL module (Dealing with a bug that could not free the streaming buffer when using Harvester). Before: Fetch all buffers from the output buffer queue and then insert all buffers into the input buffer queue After: Retrieve all buffers from output buffer queue

Mac
