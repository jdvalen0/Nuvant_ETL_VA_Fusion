Version Information

SDKs with different major versions (x part of vx.y.z) or minor versions (y part of vx.y.z) are not compatible, so program changes and rebuilds are required. An application built using SDK v1.0.x can not be executed in an environment where only SDK v1.1.x is installed. In order to make the application work, you need to rebuild using SDK v1.1.x or install SDK v1.0.x. It is possible to use multiple SentechSDK by installing them to different installation folders. For example: /opt/sentech107 for v1.0.7, /opt/sentech111 for v1.1.1, etc. However, the following precaution should be taken.

  • Multiple version of SentechSDK share the same udev rule which is located at /etc/udev/rules.d/30-stcam.rules. When uninstallation script is executed, the 30-stcam.rules will be deleted. To avoid the deletion, remove the installation directory manually without executing the stuinstall.sh script.
  • Multiple version of SentechSDK use the same environment variables but may have different value. Set the environment variables to the valid values corresponding to the version of the SentechSDK. Example: Execute "source /opt/sentech107/.stprofile" to activate the environment variables for SDK installed in the /opt/sentech107).
