PStApiGUI_IStWnd_CreateIStWnd_t CreateIStWnd

Acquire IStWnd handle. This pointer can be used for either displaying image, nodemap, or device selection.

Parameters
[in]eWndType of Window.
[in,out]pIStWndHandleIStWnd interface handle.
Attention
If the acquired IStWnd handle is no longer needed, call IStWnd->Release(pIStWndHandle) to release it.
Returns
EStApiCError_t error code.
