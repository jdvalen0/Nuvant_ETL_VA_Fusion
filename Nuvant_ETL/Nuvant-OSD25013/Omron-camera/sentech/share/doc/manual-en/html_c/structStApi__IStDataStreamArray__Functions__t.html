PStApiTL_IStDataStreamArray_RetrieveBuffer_t RetrieveBuffer

Acquire a buffer handle of IStStreamBufferReleasable from a completed transfer buffer.

Attention
Call IStStreamBuffer->Release(pIStStreamBufferHandle) when acquired buffer is no longer needed. This will release the acquired buffer back to receive buffer list.
Parameters
[in]pIStDataStreamHandleArrayIStDataStream interface handles array.
[in]nCountCount of IStDataStream interface handles.
[in]nTimeoutTimeIndicate the timeout of waiting for transfer finish (0xFFFFFFFF:Infinity).
[in,out]pIStStreamBufferHandleIStStreamBuffer Buffer handle. NULL if timeout occurred.
Returns
EStApiCError_t error code.

◆ StartAcquisition

PStApiTL_IStDataStreamArray_StartAcquisition_t StartAcquisition

Start the data acquisition from host side.

Attention
Additional IStDevice::AcquisitionStart() call is required for the device to send the data out. To stop data acquisition, call StopAcquisition().
Parameters
[in]pIStDataStreamHandleArrayIStDataStream interface handles array.
[in]nCountCount of IStDataStream interface handles.
[in]nNumToAcquireNumber of acquisition (set to GenTL::GENTL_INFINITE for infinity acquisition). The acquisition will stop after reaching this number. Nevertheless, StopAcquisition() is still needed to end the image acquisition.
[in]eAcqStartFlagsA start flags for the acquisition engine.
Returns
EStApiCError_t error code.
