Introduce parts of the defined setting items of SFNC(Standard Features Naming Convention).

Exposure time

The exposure time period configuration requires access to ExposureMode, ExposureTime, etc. ExposureMode has one of the following values: "Off", "TriggerWidth", "TriggerControlled".

ExposureModeExposure time period
Off The longest exposure time at the current frame rate.
Timed When ExposureAuto is set to enabled, the exposure time will be automatically adjusted to achieve the specified brightness. When ExposureAuto is set to disabled(Off), the exposure time will be the value of ExposureTime[us]. For the cameras which support old standards, the setting unit will be different from each cameras due to using ExposureTimeAbs and ExposureTimeRaw for setting.
TriggerWidth Exposure time period determined by the width of the trigger pulse.
TriggerControlled The timing of exposure start and stop is determined by trigger.

(Reference: Sample program AutoFunctionsC: [Windows] [Linux])

White Balance

When BalanceWhiteAuto is set to Off, the White Balance Gain can be adjusted manually. You can select the color by BalanceRatioSelector and adjust the BalanceRatio to change the setting. (Reference: Sample program AutoFunctionsC: [Windows] [Linux])

ROI

When extracting a part of an image data and transferring from a camera, use ROI function and specify the position and size (OffsetX, OffsetY, Width, Height). If more than one area can be specified, after choosing the area with RegionSelector, set the validity, position, and size of the area with RegionMode. (Reference: Sample program CameraSideROIC: [Windows] [Linux])

Decimation

The function to thin out pixels is called "Decimation". By changing DecimationHorizontal from 1 to 2, pixels are thinned out every other pixel, and the horizontal size is halved.

Saving setting to camera

To save the current setting to camera, use UserSetControl with the following steps:

  1. Select save destination with UserSetSelector(* Other than Default)
  2. Execute UserSetSave

To load the saved setting of a camera, user UserSetControl with following steps:

  1. Select load source with UserSetSelector
  2. Execute UserSetLoad

Use and set UserSetDefault to specify the setting data when the camera power is on. (Reference: Sample program UserSetCtrlC: [Windows] [Linux])

Reverse

Set ReverseX to True for horizontal reversal; set ReverseY to True for flipping upside down.

IO pin setting

To change the setting of the IO pins, specify the pin for setting with LineSelector and change the setting with LineMode, LineInverter, LineStatus, and LineSource. For example, to set Line0 to output High or Low signal, select Line0 by LineSelector and then set LineMode to Output and LineSource to UserOutput0. Set UserOutputSelector to UserOutput0 and then set UserOutputValue to change the output to High or Low.

Trigger function

Since SFNC supports various types of triggers, TriggerSelector must be specified to select the trigger type. Sample program FrameStartTriggerC ([Windows] [Linux]) demostrates the following setting and acquire image with software trigger.

  1. Set TriggerSelector to FrameStart(or ExposureStart)
  2. Set TriggerMode to On
  3. Set TriggerSource to Software
  4. Execute TriggerSoftware

To use a hardware trigger, set the Line(pin) to Input and assign it as TriggerSource.

Event

To enable the event of cameras, select the target event with EventSelector and then set EventNotification to on. (Reference: Sample code GrabCameraEventC: [Windows] [Linux])

Chunk

To enable chunk data output of camera, select the target chunk with ChunkSelector and then set ChunkEnable to true. (Reference: Sample code GrabChunkImageC: [Windows] [Linux])
