◆ SetIStImageToClipboard

PStApiTL_IStImage_SetIStImageToClipboard_t SetIStImageToClipboard

Copy a image to clipboard.

Attention
Image data in formats other than StPFNC_Mono8, StPFNC_BGR8, and StPFNC_BGRa8 will be copied to the clipboard after conversion. If you want to specify the conversion method, please convert to StPFNC_Mono8, StPFNC_BGR8, StPFNC_BGRa8 using IStPixelFormatConverter beforehand.
Returns
EStApiCError_t error code.
