◆ CreateIStSystem

PStApiTL_IStSystem_CreateIStSystem_t CreateIStSystem

Open the system module and interface module of GenTL then acquire IStSystem interface handle. If the acquired IStSystem interface handle is no longer needed, call IStSystem->Release(pSytemHandle) to release it.

Parameters
[in]eStSystemVendorGenTL module to use. The StApi functionality may differ depending on the GenTL module.
[in]eInterfaceMaskThe interface to use. For example: StInterfaceType_USB3Vision is used for USB3Vision camera. This will reduce the scanning time because only the specified interface is scanned for devices. Use logical OR to specify more than one interface.
[in,out]pIStSystemHandleISystem interface handle.
Returns
EStApiCError_t error code.
