◆ CreateIStDataStream()

virtual IStDataStreamReleasable* StApi::IStDevice::CreateIStDataStream ( size_t  nIndex = 0,
IStAllocator *  pIStAllocator = NULL 
)
pure virtual

データストリームをオープンし IStDataStreamReleasable インターフェースポインターを取得します。

注意
取得された IStDataStreamReleasable インターフェースが不要になったら、 IStDataStreamReleasable::Release() を呼び出して解放してください。
引数
[in]nIndex0から GetDataStreamCount() 未満の値でデータストリームを指定します。
[in]pIStAllocatorストリーミングに使用されるバッファの割り当ておよび解放に使用される IStAllocator インターフェースポインターを指定します。NULLが指定された場合は、StApi内部でバッファの割り当ておよび解放が行われます。
戻り値
IStDataStreamReleasable インターフェースポインター
例外
メモリー確保に失敗した場合、不正な引数が指定された場合やGenTL 関数がエラーを返した場合は、例外 GenICam::GenericException が発生します。
参照
StApi::CIStDataStreamPtr

◆ AcquisitionStart()

virtual void StApi::IStDevice::AcquisitionStart ( )
pure virtual

カメラのAcquisitionStartコマンドを実行し、カメラからのデータ出力を開始します。

注意
予め IStDataStream::StartAcquisition() を使用してホスト側のデータ取得を開始しておく必要があります。停止する場合は AcquisitionStop() を呼び出します。
例外
コマンドの実行に失敗した場合は、例外GenICam::GenericException が発生します。
参照
IStDataStream::StartAcquisition()
