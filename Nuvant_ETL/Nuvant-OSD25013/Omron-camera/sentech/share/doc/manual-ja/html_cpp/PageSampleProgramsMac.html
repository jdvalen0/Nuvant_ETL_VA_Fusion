サンプルプログラムのビルド方法

サンプルコードは/Applications/SentechSDK/Samples/シンボリックリンクでアクセスできます。

  • Objective-CサンプルGrabCocoaはXCodeで開いて、ビルドしてください。
  • C++サンプルコードをビルドするために、Xcodeコマンドラインツールインストールしてください。
  • CMakeを利用する場合はCMake 3.2以降が必要となります。
  • OpenCVが必要なサンプルコード(OpenCV)をビルドする際にOpenCV用のコンパイルフラッグはpkg-configで設定されます。 pkg-configがインストールされていない場合はMakefile或いはCMakelists.txtを編集してください。
  • OverlayQtとStViewerQtのビルドはQt SDKが必要となります。

C++のビルド方法は三つあります：

  • CMake (バージョン>=3.2):
    • ビルドディレクトリーを作成してください。例：
      $ mkdir ~/samplebuild
    • cmakeの実行:
      $ cd ~/samplebuild
      $ cmake /Applications/SentechSDK/Samples/C++
    • makeの実行:
      $ make
    • コンパイル結果は~/samplebuild/にある各サンプルプログラムのディレクトリーで実行できます。
    サンプルコードごとにビルドしたい場合は、各サンプルコードのディレクトリーにあるCMakeLists.txtを使います。例：
    $ cd ~/samplebuild
    $ cmake /Applications/SentechSDK/Samples/C++/Grab
    $ make
  • Make:
    • ビルドディレクトリーを作成してください。例：
      $ mkdir ~/samplebuild
    • Makeを実行します：
      $ cd ~/samplebuild
      $ make --file=/Applications/SentechSDK/Samples/C++/Makefile
    • ~/samplebuildに実行ファイルが生成されます。
    サンプルコードごとにビルドしたい場合は、サンプルコードのディレクトリーをコピーして、makeを実行することです。例：
    $ cp -R /Applications/SentechSDK/Samples/C++/Grab ~/
    $ cd ~/Grab
    $ make
    或いはコピーせずに：
    $ mkdir ~/samplebuild
    $ cd ~/samplebuild
    $ make Grab --file=/Applications/SentechSDK/Samples/C++/Makefile
  • 上記のビルドはOverlayとStViewerが含まれていません。どちらもビルドする際に、Qt SDKが必要です。Qtインストール方法はhttp://doc.qt.io/qt-5/Mac.htmlをご参照ください。
    Qt SDKをインストールされた場合は、Qt Creatorでプロジェクトファイル(*.pro)を開いて、コンパイルしてください。StViewerをコンソールでコンパイルする場合、下記のようになります。
    • ビルドディレクトリーを作成してください。例：
      $ mkdir ~/samplebuild
    • qmakeの実行：
      $ cd ~/samplebuild
      $ qmake /Applications/SentechSDK/Samples/C++/StViewerQt/StViewer
    • makeの実行:
      $ make
    • コンパイル結果は~/samplebuildで実行できます。
    注意
    • qmakeにパスが通っていない場合はフルパスで実行してください。例：Qt 5.8.0が/opt/Qt5.8.0へインストールされた場合、/opt/Qt5.8.0/5.8/clang_64/bin/qmake のようになります。
    • 実行の時Qtプラグインがロードできないエラーが発生する場合は環境変数QT_PLUGIN_PATHをQt SDKのプラグインフォルダに書き換えてください。例： $ export QT_PLUGIN_PATH=/opt/Qt5.8.0/5.8/clang_64/plugins

Grab

最初に見つかったカメラを使用して、画像データの取得を行います。画像データの転送が完了するまでスレッドを待機させ、取得した画像のBlockIDやサイズを表示します。 nCountOfImagesToGrab で指定した枚数(初期状態では100枚)の画像が取得されると、ストリーミングが停止します。 GENTL_INFINITE を指定すると取得する画像の枚数が無制限になります。

カメラのオープンクローズなどのログが表示されます。
