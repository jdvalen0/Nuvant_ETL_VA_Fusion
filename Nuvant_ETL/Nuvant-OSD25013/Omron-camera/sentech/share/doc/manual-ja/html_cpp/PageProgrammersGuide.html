StApiの構成

StApiは、USB3Vision, GigEVision, CoaXPressカメラ用のAPIです。APIの機能は大きく3つに分類されます。

  1. カメラ制御機能(Transport Layer)
    カメラの設定変更や画像データ、イベントデータ等を取得する機能が提供されます。カメラとの通信にはGenTLモジュールが使用されます。SDK付属のGenTLモジュールはUSB3VisionおよびGigEVisionに対応しています。CoaXPress用取り込みボードメーカー製のGenTLモジュールを使用することでCoaXPressカメラも利用できます。カメラの設定変更にはGenApiが使用されます。画像処理機能やGUI機能が不要であれば、この機能(下図の水色線枠内)だけを使用してアプリケーションを開発できます。
    モジュール主な用途
    SystemCTIファイル(GenTL用DLLファイル)の情報取得に使用されます。
    Interfaceインターフェースに関する設定や接続されているカメラの情報取得などに使用されます。
    Deviceカメラの設定に使用されます。
    Data Stream画像データ等のストリーミングの設定に使用されます。
    Stream Bufferストリーミングに使用されているバッファの情報取得に使用されます。
  2. 画像処理機能(Image Processing)
    フォーマット変換(ベイヤー画像の色補間処理)やFFCなどの画像処理や、静止画ファイル, 動画ファイルの生成機能が提供されます。提供される機能は大きく下記の3つに分類されます。
    タイプ特徴
    Filter 入力された画像データが処理後のデータで上書きされます。ピクセルフォーマットは変化しません。
    モジュール用途
    Field Flat Correction Filter照明ムラ等に対する補正に使用されます。
    Noise Reduction Filterノイズ軽減処理に使用されます。
    Gamma Correction Filterガンマ補正に使用されます。
    Edge Enhancement Filterエッジ強調に使用されます。
    Color Transformation FilterRGBデータに対する行列演算に使用されます。
    Chroma Suppression Filter高輝度部/低輝度部の着色を抑制に使用されます。
    Balance Ratio Filterホワイトバランス処理に使用されます。カメラ側にホワイトバランス処理が実装されている場合は、不要な機能です。
    Graph Data Filterグラフ表示用データの生成に使用されます。
    Image Averaging Filter平均化された画像データの生成に使用されます。
    Converter 指定したバッファへ画像データが出力されます。ピクセルフォーマットが変化することがあります。
    モジュール用途
    Pixel Format Converterピクセルフォーマット変換に使用されます。
    Reverse Converter画像の上下左右反転処理や回転処理に使用されます。カメラ側に上下左右反転が実装されている場合は、PCの負荷を軽減するため、カメラ側の処理を使用してください。
    Filer 静止画ファイルや動画ファイルを生成します。
    モジュール主な用途
    Still Image Filer静止画ファイルの保存に使用されます。
    Video Filer動画ファイルの保存に使用されます。
  3. GUI機能
    GUIが提供されます。
    モジュール主な用途
    Device Selectionカメラ選択ウィンドウの表示に使用されます。
    Image Displayプレビューウィンドウの表示に使用されます。
    Node Map Displayノードマップ表示(設定)ウィンドウの表示に使用されます。
    Graph Displayグラフ表示ウィンドウの表示に使用されます。
StApi アプリケーションの構成

対応環境

StApiは下記の環境に対応しています。

  • Linux
    Linuxテスト環境は下記のとおりです。
    • Ubuntu 18.04 (x86_64/aarch64)
    • Raspberry Pi OS (32-bit)
    取り込みボードメーカーのGenTLモジュールをご使用になる場合は、そのGenTLモジュールの対応環境により制限される場合があります。

  • Mac OS (動作確認済み：Mojave 10.14.6とCatalina 10.15.3)

StApiは下記の開発環境に対応しています。

  • Linux OS: GNU gcc (c++11規格以降)、GUI機能：Linux OSディストリビューションに配布されたQt ライブラリ

  • Mac OS: 確認済み開発環境はXCode 11.3、Qt 5.8.0

エラー処理

StApiでエラーが発生した際には GenICam::GenericException から派生された例外が発生します。下記のようなコードで例外を捕捉できます。

try
{
//例外を発生する処理
}
catch (const GenICam::GenericException &e)
{
std::cerr << "An exception occurred." << std::endl << e.GetDescription() << std::endl;
}

画像データの取得までの流れ

  1. インクルードファイルをインクルードし、使用するネームスペースを指定します。
    #include <StApi_TL.h>
    using namespace StApi;
    void main()
    {
  2. StApiライブラリの初期化を行います。
    StApiInitialize() を呼び出しStApiライブラリの初期化を行います。StApiライブラリを使い終わった後は StApiTerminate() を呼び出して終了処理を行います。下記のコードでは StApi::CStApiAutoInit のコンストラクタから StApiInitialize() が、デストラクタから StApiTerminate() が呼び出されます。
    CStApiAutoInit objStApiAutoInit;
  3. システム(GenTLモジュール)を開き、 StApi::IStSystemReleasable を取得します。
    CreateIStSystem() を使用し StApi::IStSystemReleasable を取得します。 StApi::IStSystemReleasable を使い終わった後は StApi::IStSystemReleasable::Release() を呼び出してStApi内部に生成されたオブジェクトを破棄する必要があります。下記のコードでは StApi::CIStSystemPtr のデストラクタから StApi::IStSystemReleasable::Release() が呼び出されるため、手動で呼び出す必要はありません。
    CIStSystemPtr pIStSystem(CreateIStSystem());
  4. デバイス(カメラ)をオープンし、 StApi::IStDeviceReleasable を取得します。
    StApi::IStSystem::CreateFirstIStDevice() を使用して、最初に見つかったデバイスに対する StApi::IStDeviceReleasable を取得します。 StApi::IStDeviceReleasable を使い終わった後は StApi::IStDeviceReleasable::Release() を呼び出してStApi内部に生成されたオブジェクトを破棄する必要があります。下記のコードでは StApi::CIStDevicePtr のデストラクタから StApi::IStDeviceReleasable::Release() が呼び出されるため、手動で呼び出す必要はありません。
    CIStDevicePtr pIStDevice(pIStSystem->CreateFirstIStDevice());
  5. データストリームをオープンし、取得した StApi::IStDataStreamReleasable を使用して画像データの取得を開始します。
    StApi::IStDevice::CreateIStDataStream() を使用して StApi::IStDataStreamReleasable を取得し、画像データの取得を開始します。 StApi::IStDataStreamReleasable を使い終わった後は StApi::IStDataStreamReleasable::Release() を呼び出してStApi内部に生成されたオブジェクトを破棄する必要があります。下記のコードでは StApi::CIStDataStreamPtr のデストラクタから StApi::IStDataStreamReleasable::Release() が呼び出されるため、手動で呼び出す必要はありません。
    CIStDataStreamPtr pIStDataStream(pIStDevice->CreateIStDataStream(0));
    pIStDataStream->StartAcquisition(100);
  6. StApi::IStDevice::AcquisitionStart() を呼び出し、カメラから画像データの出力を開始します。
    pIStDevice->AcquisitionStart();
  7. 画像データが入ったバッファの取得と、使用済バッファのキューへの挿入を繰り返し行います。
    StApi::IStDataStream::RetrieveBuffer() を呼び出すと、データの受信を完了したバッファの StApi::IStStreamBufferReleasable が取得できます。取得した StApi::IStStreamBufferReleasable が不要になったら、再度受信に使用するため StApi::IStStreamBufferReleasable::Release() を呼び出し、転送バッファーキューに挿入します。下記のコードでは StApi::CIStStreamBufferPtr のデストラクタから StApi::IStStreamBufferReleasable::Release() が呼び出されるため、手動で呼び出す必要はありません。
    while(pIStDataStream->IsGrabbing())
    {
    CIStStreamBufferPtr pIStStreamBuffer(pIStDataStream->RetrieveBuffer(5000));
    if(pIStStreamBuffer->GetIStStreamBufferInfo()->IsImagePresent())
    {
    IStImage *pIStImage = pIStStreamBuffer->GetIStImage();
    std::cout << "\r BlockId=" << pIStStreamBuffer->GetIStStreamBufferInfo()->GetFrameID()
    << " Size:" << pIStImage->GetImageWidth() << " x " << pIStImage->GetImageHeight()
    << " First byte =" << (uint32_t)*(uint8_t*)pIStImage->GetImageBuffer();
    }
    else
    {
    std::cout << "Image data is not exist" << std::endl;
    }
    }
  8. カメラからの画像の出力を停止します。
    pIStDevice->AcquisitionStop();
  9. 画像の取得を停止します。
    pIStDataStream->StopAcquisition();
    }

画像データ取得

画像データを取得する方法には、2つの方法があります。 一つは上記のサンプルのように画像データが取得されるまでスレッドを「待機」させる方法です(参照：サンプルプログラム『Grab』)。 もう一つは、予め登録された関数が画像データを取得したタイミングで呼び出(コールバック)される方法です(参照：サンプルプログラム『GrabCallback』)。

コールバック

本SDKで使用されるコールバック関数には大きく2種類あります。1つは「StApi」独自のもの、もう一つは「GenApi」のものです。StApiのコールバック関数は、StApiで生成されるモジュールに対して登録されます。例えば IStDataStream インターフェースを使用してDataStreamモジュールにコールバック関数を登録すると、画像データが取得されたタイミングなどで登録された関数が呼び出されます。GenApiのコールバック関数はXMLファイル(カメラなどの設定項目が記述されたテキストファイル)をもとに生成されたノードマップの各ノード(設定項目)に対して登録されます。 Eventに関連したノードにコールバック関数を登録すると、Event発生時にコールバック関数が呼び出されます。

Linux インストーラーとアンインストーラー

インストールする際は、SentechSDK-xxx-xxx.tgzを解凍し、インストーラー（.runファイル）を実行してください（スーパーユーザーのパスワードが必要）。

$ tar xf SentechSDK-xxx-xxx.tgz
$ cd SentechSDK-xxx-xxx
$ ./SentechSDK-xxx-xxx.run

インストールパスの既定値は/opt/sentechになります。インストールパスはSTAPI_ROOT_PATH環境変数に保存されます。 全ての質問に対して自動でYesと返答し、インストール先を/opt/sentechに設定する場合は、以下のようなコマンドを実行します。

$ ./SentechSDK-xxx-xxx.run --accept -- "-y -p /opt/sentech"

インストール結果は下記のとおりです。

Path for using sentech SDK

自動的に設定したい場合は、「source ${STAPI_ROOT_PATH}/.stprofile」をログインスクリプトに追加してください:
$ echo 'source ${STAPI_ROOT_PATH}/.stprofile' >> $HOME/.bashrc
或いは、グローバルで全てのユーザーに適用したい場合はスーパーユーザーで/etc/profile.d/stprofile.sh へ/opt/sentech/.stprofileをコピーください：
$ sudo cp ${STAPI_ROOT_PATH}/.stprofile /etc/profile.d/stprofile.sh
