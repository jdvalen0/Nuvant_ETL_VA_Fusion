◆ GetROIImage()

virtual IStImage* StApi::IStImage::GetROIImage ( size_t  x,
size_t  y,
size_t  width,
size_t  height 
)
pure virtual

切り取った画像用の IStImage インターフェースポインターを取得します。 データのコピーは行われず、元のデータが参照されます。そのため、元の画像が変化したり、再度この関数が呼び出された場合は、以前取得された IStImage は無効になります。

引数
[in]x横方向のオフセット値
[in]y縦方向のオフセット値
[in]widthROI画像の横サイズ
[in]heightROI画像の縦サイズ
戻り値
IStImage インターフェースポインター
例外
不正な引数が指定された場合は、例外GenICam::GenericException が発生します。

◆ GetIStPixelComponentValue()

virtual IStPixelComponentValue* StApi::IStImage::GetIStPixelComponentValue ( size_t  x,
size_t  y 
)
pure virtual

指定した位置の画素情報を取得します。

引数
[in]x横方向の位置
[in]y縦方向の位置
戻り値
IStPixelComponentValue インターフェースポインター
注意
再度この関数が呼び出されると、 IStPixelComponentValue インターフェースポインターを使用して得られる値が変化します。取得された IStPixelComponentValue インターフェースポインターは元の画像が破棄されると無効になります。
例外
不正な引数が指定された場合は、例外GenICam::GenericException が発生します。
