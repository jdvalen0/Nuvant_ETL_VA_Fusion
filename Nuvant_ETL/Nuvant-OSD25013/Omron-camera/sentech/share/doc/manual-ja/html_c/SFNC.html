SFNC(Standard Features Naming Convention)で規定されている設定項目の一部を紹介します。

露光時間

露光時間の設定には、 ExposureMode や ExposureTime などが使用されます。ExposureModeは Off, Timed, TriggerWidth, TriggerControlled のいずれかの値となります。

ExposureMode露光時間
Off 現在のフレームレートでの最長時間となります。
Timed ExposureAutoが有効(Off以外)になっている場合、露光時間は指定された明るさになるように自動で制御されます。ExposureAutoが無効(Off)になっている場合、露光時間はExposureTime[us]で設定した値となります。古い規格に対応しているカメラでは、ExposureTimeAbs, ExposureTimeRawが使用されており、設定単位がカメラにより異なっています。
TriggerWidth トリガーパルスの幅で決まります。
TriggerControlled 露光開始と終了のタイミングが、トリガーで指定されます。

(参照:サンプルプログラム 『AutoFunctionsC』：【Windows】【Linux】)

ホワイトバランス

BalanceWhiteAutoをOffに設定すると、ホワイトバランスゲインを手動で設定できるようになります。 BalanceRatioSelector で設定する色を選択してから、 BalanceRatio を設定します。 (参照:サンプルプログラム 『AutoFunctionsC』：【Windows】【Linux】)

ROI

画像データの一部分のみを切り出してカメラから転送させる場合、位置とサイズは OffsetX, OffsetY, Width, Heightで指定します。複数の領域を指定できる場合は、指定する領域を RegionSelector で選択した後に、 RegionMode でその領域の有効/無効および位置とサイズを指定します。 (参照:サンプルプログラム 『CameraSideROIC』：【Windows】【Linux】)

間引き

画素を間引く機能は、SFNCではDecimationHorizontal/DecimationVerticalと呼ばれます。DecimationHorizontalを1から2へ変えると、1画素おきに画素が間引かれるようになり、横サイズが半分になります。

カメラへの設定保存

現在の設定値をカメラへ保存する際は、下記の手順でUserSetControl機能を使用します。

  1. UserSetSelector で保存先を選択(※ Default以外)
  2. UserSetSave を実行

保存された設定をカメラへ反映する際は、下記の手順でUserSetControl機能を使用します。

  1. UserSetSelector で読み込み元を選択
  2. UserSetLoad を実行

電源投入時に反映すべきデータは、 UserSetDefault で指定します。 (参照:サンプルプログラム　『UserSetCtrlC』：【Windows】【Linux】)

上下左右反転

左右反転時は ReverseX を、上下反転時は ReverseY を True へ設定します。

IO端子設定

IO端子の設定は設定を行う端子を LineSelector で指定した後、 LineMode, LineInverter, LineStatus, LineSource を設定します。Line0からHighまたはLowを出力する場合は、LineSelector に Line0を指定し、LineMode を Output へ設定した上で、LineSource を UserOutput0 へ設定します。HighまたはLowへの設定は、UserOutputSelectorにUserOutput0を指定した後, UserOutputValueを設定します。

トリガー機能

SFNCでは様々なトリガーの実装が想定されているため、トリガーの設定を行う前に、どのトリガーに対する設定を行うのかをTriggerSelectorで指定します。 サンプルプログラム　『FrameStartTriggerC』 (【Windows】【Linux】) では下記の設定を行いソフトウェアトリガーで画像を取得します。

  1. TriggerSelector を FrameStart (または ExposureStart )へ設定
  2. TriggerMode を On へ設定
  3. TriggerSource を Software へ設定
  4. TriggerSoftware を実行

ハートトリガーを使用する際は、使用する Line (端子)を、予め Input に設定した上で、 TriggerSource へ指定します。

イベント

カメラ等からのイベントの取得を有効にするには、有効にするイベントを EventSelector で選択した後、 EventNotification を On に設定します。 (参照:サンプルプログラム 『GrabCameraEventC』：【Windows】【Linux】)

チャンク

カメラからのチャンク出力を有効にするには、有効にするチャンクを ChunkSelector で選択した後、 ChunkEnable を true に設定します。 (参照:サンプルプログラム 『GrabChunkImageC』：【Windows】【Linux】)
