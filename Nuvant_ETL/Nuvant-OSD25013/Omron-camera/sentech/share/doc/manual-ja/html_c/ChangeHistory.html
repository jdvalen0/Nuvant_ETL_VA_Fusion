StApiの更新履歴です。

v1.1.2 Update 5 (2021.09.30)

共通

  • GigEVisionカメラをオープン後のHeartbeatTimeout更新に対応しました。
  • StViewerのプレビュー画像に対するピクセルフォーマット変換設定の保存に対応しました。
  • べイヤー色補間(デモザイク)方法へ StBayerInterpolationMethod_BiLinear3 を追加し、静止画保存時のデフォルトフォーマットとして選択されるように変更しました。
  • StApiCのIStStreamBufferInfoの関数GetTimestampNSの値の型がuint64_tではなくint64_tになっている不具合を修正しました。

Windows

  • SentechSDKインストール時にStViewer,StFWUpdater, GigECameraIPConfigの通信許可設定がファイアウォールへ追加されるようにしました。
  • StViewerで連続静止画保存機能を使用した際に保存枚数の設定が機能しない不具合を修正しました。
  • Tool(StFWUpdater, GigECameraIPConfig, StPowerCtrl)の64ビット版をインストーラーへ追加し、32ビット版のDLLをインストールしなくてもToolが使用できるようにしました。
  • Windows11環境でノードマップ設定画面のボタンの文字列が重なって表示されてしまう不具合を修正しました。

Linux

  • EventGetDataの呼び出し前にイベントが発生すると、GC_ERR_ERRORが返されることがある不具合を修正しました。
  • ActionCommandに対するGigEVisionカメラからのAckを初回しか取得できない不具合を修正しました。

Mac

  • EventGetDataの呼び出し前にイベントが発生すると、GC_ERR_ERRORが返されることがある不具合を修正しました。
  • ActionCommandに対するGigEVisionカメラからのAckを初回しか取得できない不具合を修正しました。

v1.1.2 Update 4 (2021.04.30)

共通

  • SN測定フィルターの(空間的な)SN値算出時の不具合を修正しました。
  • CoaXPressカメラ使用時にフレームレートが低下することがある不具合を修正しました。
  • エッジ強調( StApi::IStEdgeEnhancementFilter )機能が下記のフォーマットに対応しました。
    • StPFNC_YCbCr8
    • StPFNC_YCbCr8_CbYCr
    • StPFNC_YCbCr709_8_CbYCr
    • StPFNC_YCbCr601_8_CbYCr
    • StPFNC_YUV8_UYV
    • StPFNC_YCbCr422_8
    • StPFNC_YCbCr709_422_8
    • StPFNC_YCbCr601_422_8
    • StPFNC_YUV422_8
    • StPFNC_YCbCr422_8_CbYCrY
    • StPFNC_YCbCr709_422_8_CbYCrY
    • StPFNC_YCbCr601_422_8_CbYCrY
    • StPFNC_YUV422_8_UYVY
  • GenTLモジュールにUSB3Visionカメラのストリーミング時のペイロードサイズを手動で設定する機能(ManualPayloadSizeMode, ManualPayloadSize)を追加しました。

Windows

  • PNGファイル読み込み時の不具合を修正しました。
  • StViewerに連続した静止画を保存する機能を追加しました。
  • デバイス選択画面でNICやGigEVisionカメラのIPアドレス/サブネットマスクが表示されないことがある不具合を修正しました。
  • WebM形式(VP8)の動画保存に対応しました。
  • USB3Vision非対応カメラ(STC-MBA5MUSB3/STC-MCA5MUSB3)に対応しました。
  • NICのサブネットマスク設定のネットワーク部の長さが8の倍数になっていない(サブネットマスクの10進数表記に255または0以外の数値が含まれる)場合、GigEVisionカメラをオープンできない不具合を修正しました。
  • GigEVisionカメラのActionCMDを使用すると、CPU負荷が上昇したままになってしまう修正しました。
  • DirectShowフィルターのレジストリー設定をファイルへエクスポートする際にアプリケーションが異常終了することがある不具合を修正しました。
  • .NET Framework 4.0に対応しました。詳細につきましては、StApiDotNET_Jpn.chmまたはStApiDotNET_Eng.chmをご参照ください。
  • GigEVisionカメラのGevSCFTD, GevSCPD検討用ソフトStGevDelayを追加しました。

Linux

  • サブネットが異なるGigEVisionカメラをオープンできない不具合を修正しました。
  • Zero Copyが機能しない一部の環境で、USB3Visionカメラから画像データが取得できない現象に対して、Zero Copyを無効化する機能を追加しました。環境変数「STGENTL_U3V_DISABLE_ZERO_COPY」が定義されている場合、Zero Copyが無効化されます。以下のようにStViewerを起動すると、Zero Copyが無効な状態になります。
    $ export STGENTL_U3V_DISABLE_ZERO_COPY
    $ /opt/sentech/bin/StViewer

v1.1.2 Update 3 (2020.10.30)

共通

  • PNGファイルの読み込みに対応しました(ファイルの形式によっては読み込めないこともあります)。16ビット画像として保存された、10,12ビットの画像を読み込むと画素値が小さな暗い画像になります。また、インディックスカラーの画像ファイルはモノクロ画像として画素値のみが読み込まれます。
  • 偏光画像に対する画像処理(Cosinカーブによって補間された指定角度の画像算出)を追加しました。
  • 画像表示ウィンドウのTextOfLengthUnit, TextOfAreaUnit,TextOfAngleUnitに % を含む文字列を指定すると、意図しない値が表示されたり、アプリケーションが異常終了したりすることがある不具合を修正しました。

Windows

  • StViewer上でのBMP,PNGファイルの読み込みに対応しました(ファイルの形式によっては読み込めないこともあります)。
  • Matrox社製Matrox Vision Libraryがインストールされている環境で正常に動作しないことがある不具合を修正しました。
  • 環境変数GENICAM_GENTL32_PATH/GENICAM_GENTL64_PATHに260文字を超えるパスが指定されていると、バッファオーバーランが発生する不具合を修正しました。

Linux

  • USB3VisionカメラをHigh Speed(USB 2.0)で接続した際にタイムアウトエラーが発生することがある不具合を修正しました。

Mac

  • USB3VisionカメラをHigh Speed(USB 2.0)で接続した際にタイムアウトエラーが発生することがある不具合を修正しました。

  • パスに\ではなく/が含まれていると、ファイルが保存できないことがある不具合を修正しました。

  • GenTLモジュールのEventFlush関数を処理を変更しました(Harvester使用時にストリーミングバッファを解放できない不具合対応)。 変更前：出力バッファキューから全バッファを取り出し後、全バッファを入力バッファキューへ挿入 変更後：出力バッファキューから全バッファを取り出し

Mac
